✍️ AI Blog Writer

A multi-agent AI system that autonomously researches a topic, plans and generates structured blog content, extracts relevant sources, and produces a professionally formatted PDF.

🚀 Features

- 🤖 Multi-agent architecture for automated blog generation
- 🔎 AI-powered web research and information gathering
- 🧠 Intelligent topic analysis and content planning
- 📝 Section-wise blog generation
- 🔗 Relevant source and reference links
- 📄 Automated professional PDF generation
- 🎯 Clean, structured, and reader-friendly output

🛠️ Tech Stack

- Python
- LangChain / LangGraph
- Large Language Models (LLMs)
- Web Search Tools
- ReportLab
- Streamlit
- Git & GitHub

🔄 Multi-Agent Workflow

User Topic
    ↓
Research Agent
    ↓
Planning Agent
    ↓
Content Generation Agents
    ↓
Source / Reference Extraction
    ↓
Blog Formatting
    ↓
PDF Generation
    ↓
Final Blog
